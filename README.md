Me chamo **Pedro**, estudante de Ciência da Computação na UEPB.

Tenho interesse em construir soluções inteligentes que conectam dados, modelos de Machine Learning e aplicações baseadas em Inteligência Artificial.

* ⚙️ Engenharia de Dados e pipelines ETL.

> Meu objetivo é desenvolver soluções que unam fundamentos técnicos, qualidade de código e aplicações práticas.
